## Description

The contract currently accepts stealth meta-addresses as raw 64-byte arrays. This issue
requires adding support for the ERC-6538 standard format, making it interoperable with
EVM-based stealth address implementations.

## What to do

1. Add meta-address encoding/decoding functions in the contract
2. Update the SDK to support ERC-6538 format meta-addresses
3. Ensure backward compatibility with raw byte format
4. Add tests for both formats
5. Update documentation with format details
